MIGRATION GUIDE: UserRegistration to UserRegistrationV2
=======================================================

To use the new UserRegistrationV2 component (Shadcn/UI version), update your imports:

BEFORE:
-------
import UserRegistration from "./UserRegistration";

AFTER:
------
import UserRegistrationV2 from "./UserRegistrationV2";

In AppContent.js, update line 18 and 102:
-----------------------------------------
Line 18:
  import UserRegistrationV2 from "./UserRegistrationV2";

Line 102:
  <UserRegistrationV2 />
